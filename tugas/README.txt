PETUNJUK PENYIMPANAN FILE TUGAS KULIAH:
=========================================
Folder ini digunakan untuk menyimpan dokumen/berkas tugas yang bisa diunduh atau dilihat langsung dari website portofolio.

Contoh nama file yang bisa kamu taruh di folder ini:
1. Laporan_ADPL_Luthfi.pdf
2. Diagram_UML_Perancangan_Sistem.pdf
3. Source_Code_Tugas_Praktik.zip
4. Dokumentasi_Proyek.docx

Setelah kamu menaruh file di folder ini:
1. Pastikan nama filenya sama persis dengan yang ada di atribut href="tugas/nama_file.pdf" pada index.html.
2. Jalankan:
   git add .
   git commit -m "feat: tambahkan berkas tugas kuliah"
   git push

File kamu akan langsung aktif dan bisa diunduh oleh dosen/teman dari website profil GitHub Pages!
